## 四、本次新发现并修复的缺陷（3 项）

### F-1（高·存量）IAM 创建账号后凭据弹窗不出现——`showUserCredentials` 漏导入
- **复现**：控制台 →组织与账号→创建账号→提交成功（服务端账号已建），「账号凭据」弹窗不出现，仅 toast 报错文案 `showUserCredentials is not defined`（toast 自动消失，常规手测难以察觉）。
- **根因**：R4 前端拆分（REFACTOR-2026-10-13）把 iam 页拆为五 tab 模块，`members.js:527/771` 两处调用 `showUserCredentials`，但 `helpers.js` 导入清单遗漏该名字；ReferenceError 被 `catch (error) { toast(error.message) }` 吞掉。
- **修复**：`members.js` 导入清单补 `showUserCredentials`。
- **回归**：dom-smoke T10 由 FAIL 转 PASS（含凭据弹窗、二次修改、关闭联动全链）。

### F-2（高·存量）iam 五 tab 渲染函数未接收 `ctx`——13 处 `ctx.rerender()` 必然 ReferenceError
- **复现**：创建账号后点击凭据弹窗「我已妥善传达」→ 控制台 Uncaught `ReferenceError: ctx is not defined`，页面不刷新、列表停留旧数据。凡 members/roles/groups/conflicts 任一 tab 内走「增删改后刷新」路径必触发。
- **根因**：同属 R4 拆分遗漏——`index.js:renderIam` 只把 ctx 传给 `renderConnectors`，其余四个 tab 以无参调用；而 app.js 约定 ctx=`{rerender: navigate}`（app.js:243）。
- **修复**：`index.js` 向四个 tab 贯穿传 ctx；`renderMembers/renderRoles/renderGroups/renderConflicts` 签名补 `(ctx)`。
- **回归**：dom-smoke 全量跑完「页面异常」清零。

### F-3（高·本次适配面）≤768 栅格轨道被宽内容撑破（§三根因 2）
- **修复**：base.css/home.css 文末补强段——17 类网格容器子项 `min-width:0; max-width:100%`，轨道 `minmax(0,1fr)` 收紧；`.card svg[viewBox]` 等比收缩（dashboard sparkline `width="520"` 溢出源）；`.az-table-box` 补 `overflow-x:auto`（原 overflow:hidden 会静默裁断 560px 表格）；`.modal` 小屏 padding 收窄；≤359 单列兜底。
- **回归**：375 工作台越界 54→0；320/768/面板均 0。

**测试脚本修复（非产品缺陷）**：`scripts/dom-smoke.mjs` T10/T11 仍导入已拆分删除的 `pages/iam.js` → 更正为 `pages/iam/index.js`（iam 拆分后该脚本从未真正跑到 T10/T11，属断言面盲区，F-1/F-2 正是借修复盲区后暴露）。
