## 三、任务二：线上整体性功能测试（四组并行 + 总负责人亲测）

### 3.1 G1 环境与部署冒烟组（19 用例：15 PASS / 3 WARN / 1 FAIL）

- 可用性：SPA HTML/lang/viewport ✅、TLS 证书（Google Trust Services，至 2027-01-07，余 85 天）✅、HTTP/2 + alt-svc h3 ✅。
- 静态资源 6/6（含嵌套 ES 模块抽测）、SPA fallback（/dashboard /iam /login→index.html）✅、/panel 302→/panel/ ✅、/docs 索引与文档 ✅、压缩（br/gzip 协商）✅、性能基线 0.7–1.2s（瓶颈为海外 POP RTT，见 F5）。
- **FAIL → G1-F1（P2）：`http://ybkkasi.com/` 明文口直接 200 返回完整站点，无 301/308 跳转**（会话凭证明文暴露/SEO 重复面）。修复口在 Cloudflare「Always Use HTTPS」，非代码层。
- WARN：G1-F2 公网未启用 HSTS/CSP（有 nosniff/XFO/Referrer-Policy 兜底，建议 HSTS 灰度起步）；G1-F3 `/api/*` 未知路径匿名 401 而非 404（鉴权前置 fail-closed，安全优先，建议契约文档注明口径）；G1-F4 API 响应无 Cache-Control（建议统一 `no-store`）。

### 3.2 G2 匿名安全面组（8 组 / 44 断言：43 过 / 1 缺陷）

- **全过**：受保护路径匿名 25/25 全 401 零泄漏；方法收敛（PUT/DELETE→401，GET login→404）；路径混淆 6 变体无绕过（遍历变体落 SPA 壳，无数据）；令牌攻防 4/4（伪造/空/X-Api-Key/Cookie 全拒，错误信息无情报价值）；公开端点契约（bootstrap 只回布尔、SSO 未注册身份源 400 中文、登录失败文案统一不利户枚举）；XSS 反射/open redirect 零命中；CORS 不回显恶意源；`/.env` `/package.json` `/data/admin-initial-password.txt` 均不可达。
- **缺陷 G2-01（P2）：`/docs` 公开面可枚举 69 篇文档，混入 `deploy-enterprise.md` 部署 runbook（端口/数据目录/首启口令机制/环境变量名/进程拓扑）与 40+ 篇内部工程协作文档**。全文检索确认无真实口令/密钥（占位符），故定 P2。根因：代码假设「docs 目录 = 已公开文档」（`plugin-console/src/index.ts:237-250`）与目录实际内容失配。建议：显式发布 allowlist 或独立 `docs/public/`，部署 runbook 移入鉴权后「运维手册」。
- 登录纪律：全程失败尝试 2 次（含 1 次不存在用户探针）即停，未触碰真实口令、未触发锁定（锁定机制本地代码佐证在位：5 次失败/15 分钟窗口）。
