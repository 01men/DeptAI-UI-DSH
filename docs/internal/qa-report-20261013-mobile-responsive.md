## 一、总体结论

**适配完成，三档断点全矩阵验证通过；测试过程中发现并修复缺陷 3 项（1 项为存量功能缺陷、1 项为本次适配引入后当场抓到修复、1 项为存量遮挡小缺陷）。质量门两轮全绿。**

- 移动端「变形」根因：控制台外壳 `.layout` 侧边栏固定 232px 常驻、无任何折叠机制，375px 手机上内容区仅剩约 140px；叠加顶栏搜索 320px 定宽、双列栅格不收敛、登录页双栏并排等，窄屏全面破版。
- 适配策略：CSS 三档断点（**≤1024 外壳抽屉化 / ≤768 栅格单列 / ≤560~640 紧凑**）+ 最小 JS 交互（汉堡开关、首页移动菜单），不改任何桌面视觉（断点外零规则生效）。
- 部门面板 panel-core 已有 1360/1180/980 三档响应式（既有设计），本次由并行协作者补强 ≤1024/≤768/≤420 三档（顶栏收缩、输入行折行、场景卡网格收敛），与控制台改造互补、无冲突。

## 四、缺陷清单（3 项，均已修复并回归）

### D-1（存量·高）首页页内锚点劫持 SPA 路由，首页被整页替换
- **现象**：点击首页任意 `#sec-*` 锚点（桌面导航三个链接、页脚、移动菜单均中招），hash 变为 `#sec-start` 触发 `app.js` 的 `hashchange → navigate()`，首页被整页替换成登录页/控制台，"产品能力/架构理念/快速开始"导航在桌面端本来就是坏的。
- **根因**：首页锚点 href 直接写 hash，与 SPA 路由器共享 hash 通道，无任何拦截（`js/app.js:260` 全局 hashchange 监听）。
- **修复**：`home.js` 对 `a[href^="#sec-"]` 统一 preventDefault + 显式滚动（76px 偏移）+ `replaceState` 维持 `#/home`；附加 800ms 未达位瞬时补齐兜底（部分内嵌 webview rAF 节流导致平滑滚动停滞——本测试环境实测 900ms 仅滚 73px，兜底后落点精确）。
- **回归**：375 实测 URL 保持 `#/home`、落点 `#sec-start` 顶部=76px、菜单自动收起。

### D-2（本次引入·高·测试中当场抓到）小屏弹窗溢出屏幕
- **现象**：375 视口打开审计详情弹窗，实测宽 717px、右缘 729px，溢出屏幕 354px。
- **根因**：本次响应式层把 `.modal` 写成 `max-width:100%`——弹窗是 `.modal-mask`（display:grid，auto 轨道）的网格项，**百分比 max-width 在 auto 尺寸轨道里循环解析，退化为 max-content**（被 `white-space:pre` 的代码块撑到 717px），完全绕开约束。
- **修复**：改视口单位 `width/max-width: calc(100vw - 24px)`（base.css:1186 注明原因）。
- **回归**：375 实测 344px（滚动条 8px 口径）完整可见，`fitsViewport=true`，文档级零溢出。

### D-3（存量·低）平板断点 hero 首屏被固定导航遮挡 8px
- **现象**：`home.css` 既有 ≤1060 断点把 hero `padding-top` 设 56px，而顶部导航固定高 64px，首行内容上缘被盖 8px。
- **修复**：56px → 88px。768 实测 hero 文案顶部=88px，导航下方无遮挡。

## 六、观察项（非缺陷，留档）

1. **桥接免登的测试环境现象**：测试浏览器配置存有历史 dsh 宿主 httpOnly Cookie（127.0.0.1 端口不区分），页面加载时 `boot() → exchangeBridgeSession()` 自动兑换出 admin 会话（`/dsh-bridge/session-exchange` 在独立形态返回 200，审计记录 `authn.token.issue` 可证）。属平台既有「宿主免登」设计，与本次改造无关；但意味着**共用浏览器的测试/演示环境可能"莫名单地已登录"**，排查时先看 Cookie。
2. **测试环境动画节流**：本测试浏览器 rAF/CSS 过渡被强节流（首页 canvas 生长动画半程停滞、抽屉滑入缓慢），真机不受影响；D-1 修复中的 800ms 兜底即为此类环境保险。
3. **表格横滚策略**：≤768 给 `.tbl` 设 min-width 560px——列少的表也会出现横滚，换取「列不被压碎」的一致可读性；后续如需按表豁免，可给窄表加 `.tbl-compact` 类解除。
4. **上线步骤**：本仓库不自动部署，ybkkasi.com 由服务器人工 runbook 更新（docs/deploy-enterprise.md）。合并后需在服务器 `git pull` 并重启实例，移动端适配才对线上生效；建议上线后用真机抽查 §三 矩阵中 375 档的前四行。
