技术笔记

企业 AI 资产治理，工程上到底难在哪

  • 成本归口

    模型账单月底出来，没人说得清哪个部门花的

    归口字段必须在消耗发生那一刻强制写上，而且允许它让调用失败。月底再对账，你面对的是一堆没有组织的钱。

  • 权限模型

    Agent 需要的权限是动态的，传统权限模型在这里崩掉

    难点不是给它什么权限，是这个权限什么时候失效。一个 40 毫秒的调用配一个 7 天的 token，中间所有设计都是空的。
