## 一、总体结论

**「手机端变形」根因不在代码，在部署：移动适配代码从未上线。** 证据链（§三）：`1cdfd38` 适配提交至今**未推送远程**（`ybkkasi/main` 落后 1 个提交）；线上磁盘文件 = `7fb5225` 版（base.css 59,728 字节、0 处 `minmax(0,1fr)` 适配标记）；且线上**进程比磁盘更旧**（静态资源仍回 `max-age=14400`，而 `7fb5225` 起静态服务已改 `no-cache`）——服务器拉过 `7fb5225` 但从未重启进程。

代码侧适配在本地全量验证通过（320/375/768 视口 × 工作台/表格/面板零溢出、汉堡菜单/抽屉/IAM 全链真浏览器回归），selftest 1201/1201 全绿。**剩余动作 = 提交推送（本报告入库时完成）+ 服务器按 §六 runbook 拉取重启**，线上即恢复。

整体性测试（线上 15 项 HTTP 面 + 线上 GUI 三视口 + 本地认证后回归 + 四道质量门）全部执行完毕：**线上 1 项 FAIL（80 端口未强制跳 HTTPS，属 Cloudflare 配置，代码不可修）**，其余通过或判定为设计内行为；本地质量门四道全绿。


## 八、环境事件与观察项

1. **内置浏览器 Playwright 点击全面超时**（含 `force`）：首页 canvas 粒子 rAF 循环 + 宿主节流使动作稳定性检查无法收敛——与 20261013 记录的「rAF/CSS 过渡强节流」同源。本次全程改走 `cua` 坐标路径 + `evaluate` 读态，断言以 DOM 计算样式/文本为准。
2. 本地 7301 实例的后台包装器显示「已退出」但进程实际存活（curl 探活确认），与 20261013「实例静默退出」观察相反方向，均提示宿主对后台进程的生命周期管理需留意。
3. 内置浏览器携历史 `127.0.0.1` 宿主 Cookie，boot() 经 session-exchange 自动兑换管理员会话（沈亦澜）——登录态测试直接可行，属既有已知机制。
4. data-guitest 残留历次冒烟数据（冒烟测试组织-xxxx 等，RUN_ID 可溯），属冒烟实例惯例，未清理。
