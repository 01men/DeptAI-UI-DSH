## 复跑步骤

```bash
# 0) 先确认 selftest 固定端口空闲（7311/7313/7316/7318/7319/7322/7361-7363/7399）
#    本轮两次假失败均因占用这些端口导致
npm run selftest                       # 期望 1540/1540

# 1) 拉起五组隔离实例（7341-7345 / stub 7441-7445）
for g in A B C D E; do
  case $g in
    A) p=7341; s=7441 ;; B) p=7342; s=7442 ;; C) p=7343; s=7443 ;;
    D) p=7344; s=7444 ;; E) p=7345; s=7445 ;;
  esac
  node qa-runtime-20261021/setup-group.mjs $g $p $s
done

# 2) 五组实测
for g in a b c d e; do node qa-runtime-20261021/group-$g.mjs; done

# 3) 缺陷证据（可单独复跑，用于修复前后对比）
node qa-runtime-20261021/repro/external-no-org.mjs
node qa-runtime-20261021/repro/permit-decisive.mjs
node qa-runtime-20261021/repro/uhp-sse-direct.mjs
node qa-runtime-20261021/repro/top-level-taskid.mjs
node qa-runtime-20261021/repro/state-machine-terminal.mjs

# 4) 收尾
pkill -f "data-qa-g" ; pkill -f "qa-runtime-20261021/model-stub.mjs"
```

## 修复后复验口径

| 缺陷 | 修复验收标准 |
|---|---|
| P1-01 | `external-no-org.mjs` 输出 `verdict: PASS`（tasks/get 返回同一 taskId、tasks/list 含该任务、SSE 200、cancel 200） |
| P2-01 | `permit-decisive.mjs` 输出 `code: PERMIT_NOT_EFFECTIVE` |
| P2-02 | `curl /v1/uhp` 顶层直接是 `uhp_version`，无 `ok/data` 包裹 |
| P2-03 | `uhp-sse-direct.mjs` 输出 `eventsSeen` 含 `response.completed` |
| P2-04 | `top-level-taskid.mjs` 中 topSnake/topCamel 均 400 或 `ignored_fields` 含 `task_id` |
| P2-05 | 组C `C3` 两语缺失数 ≤ 5（≥95%） |
| P2-06 | `grep -c EventSource packages/plugin-console/public/js/pages/a2a.js` ≥ 1 |

## 环境注意事项

- 五组实例的模型 endpoint 由 `setup-group.mjs` 统一改写到本组 stub；若手工起实例，需自行执行 `POST /api/modelgw/models`（upsert，非 PATCH）改 endpoint。
- 账号令牌 TTL 较短（约 30 分钟），脚本采用「用例前实时登录」，`group-*.json` 中的静态 token 仅作参考。
- `dshctl` 的连接目标变量是 `DSHCTL_URL`（不是 `DSH_BASE`），令牌用 `DSHCTL_TOKEN` 或前置 `--token=`。
- `a2a.js` 在 Node 侧加载需补 jsdom 全局（document/window/MutationObserver/NodeFilter/Node/Text），`page-smoke.mjs` 已有同类处理。
